# 📋 Task Manager - Modern Kanban Board

Современный менеджер задач с визуальной Kanban-доской, дашбордом аналитики и **диаграммой Ганта**.

## ✨ Возможности

- **Kanban-доска** — 3 колонки (Todo → In Progress → Done)
- **Приоритеты** — Low/Medium/High с цветовой индикацией
- **Дедлайны** — отслеживание сроков с подсчётом дней
- **Учёт времени** — фиксация затраченных часов
- **Дашборд** — статистика, графики, прогресс выполнения
- **Диаграмма Ганта** — визуализация задач во времени относительно месяца
- **Offline режим** — работает без интернета
- **JSON-хранилище** — данные сохраняются локально

## 🏗️ Архитектура

```
task_manager/
├── main.py              # Точка входа
├── requirements.txt     # Зависимости
├── src/
│   ├── core/           # Domain Layer
│   │   ├── models.py   # Task, TaskStatus, Priority
│   │   ├── repository.py  # TaskRepository (JSON storage)
│   │   └── service.py  # TaskService (business logic)
│   ├── gui/            # Presentation Layer
│   │   ├── main_window.py  # UI компоненты
│   │   └── gantt_view.py   # Диаграмма Ганта
│   └── utils/          # Utilities
│       └── helpers.py  # Вспомогательные функции
├── data/               # Хранилище задач (tasks.json)
└── dist/               # EXE-билд
    └── TaskManager     # Standalone executable
```

## 🚀 Быстрый старт

### Из исходников:
```bash

```

### Из EXE:
```bash

```

## 📦 Сборка в EXE

```bash
pip install pyinstaller
pyinstaller --onefile --name "TaskManager" main.py
```

Результат: `dist/TaskManager` (~7 MB)

## 🎯 Использование

1. Нажмите **"➕ Новая задача"** для создания
2. Заполните поля: заголовок, описание, приоритет, дедлайн
3. Перемещайте задачи между колонками через редактирование
4. Откройте вкладку **"📈 Аналитика"** для графиков
5. Откройте вкладку **"📅 Диаграмма Ганта"** для просмотра задач во времени

## ✅ SOLID принципы

- **SRP** — каждый класс отвечает за одну задачу
- **OCP** — легко расширять через наследование
- **LSP** — подтипы заменяемы без нарушений
- **ISP** — минималистичные интерфейсы
- **DIP** — зависимости через абстракции

## ⚡ Производительность и Архитектура

### Оптимизации производительности:
- **Селективное обновление** — перерисовка только затронутых колонок вместо всей доски
- **Кэширование ссылок на колонки** — быстрый доступ без поиска виджетов
- **Отложенные обновления UI** — использование `after()` для неблокирующих операций
- **Минимизация операций с JSON** — пакетное сохранение данных

### Архитектурные улучшения:
- **Чёткое разделение слоёв** — Domain (core), Presentation (gui), Utils
- **Единый источник истины** — TaskService управляет состоянием задач
- **Реактивные обновления** — изменения в сервисе автоматически обновляют UI
- **Инверсия зависимостей** — сервис внедряется в GUI компоненты
- **Принцип единственной ответственности** — каждый класс решает одну задачу
